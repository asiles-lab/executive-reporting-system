Arquitectura de producto

Mismo motor. Distintas métricas. Distinto resultado ejecutivo.

Cada rol necesita una lectura distinta. Un gerente quiere control, un consultor necesita demostrar valor, ventas mira pipeline, operaciones mira pérdidas y un dueño necesita foco. Cambia el input, cambia la narrativa, se mantiene el método.
